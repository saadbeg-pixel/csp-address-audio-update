# CSP Address Audio Update

Design spec for the Wiom Partner App booking decision screen: the redesigned audio
address player, the single "पता नहीं समझ आया ?" entry point that opens two options
(call the customer, or see nearby connections), and the tightened card spacing.

`index.html` is a self-contained page, published at
https://saadbeg-pixel.github.io/csp-address-audio-update/

**Internal-facing.** Excluded from search engines (noindex + robots.txt), but anyone
with the link can read it.
